# Farmaura App - Sistema de Gestión de Farmacia

Aplicación de escritorio desarrollada en Python con interfaz moderna en CustomTkinter para la gestión de inventario, registro de ventas y exportación de reportes comerciales.

---

## Requisitos Previos

Asegúrate de contar con el siguiente entorno antes de ejecutar el software:

* **Python:** Versión 3.10 o superior (recomendado Python 3.12).
* **Gestor de paquetes:** `pip` actualizado.

---

## Dependencias

El sistema utiliza las siguientes librerías:

| Librería | Propósito |
| :--- | :--- |
| `customtkinter` | Interfaz gráfica moderna y personalizable |
| `pandas` | Procesamiento, cálculo y manipulación de DataFrames[cite: 1, 2] |
| `openpyxl` | Exportación de reportes en formato Excel (`.xlsx`) |
